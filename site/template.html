Agri Field Monitor

Backend for monitoring Alternate Wetting and Drying (AWD) rice irrigation: fields, pipes, water-level readings, alerts and weekly reports behind a GraphQL API, with REST endpoints for token issuance and visit photo uploads.

Source on GitHub Open in Codespaces Deploy to Render

This page is a static schema reference exported with strawberry export-schema on every push to main; there is no backend behind it. Open the Codespace for a running GraphiQL at /graphql/ with seeded demo data (login agent / agent1234), or deploy your own copy to Render.

REST endpoints

Everything else is GraphQL at POST /graphql/. Operations other than login need Authorization: Bearer <jwt>.

MethodPathAuthDescription
GET/health/noneLiveness probe: {status, database}
POST/api/v1/auth/token/none{username, password} to {token, token_type, expires_in}
POST/api/v1/visits/{id}/photos/BearerMultipart image (+ caption); jpg, jpeg, png, webp; 5 MB default
GET/api/v1/visits/{id}/photos/BearerPhotos of a visit with absolute URLs
POST/graphql/BearerGraphQL endpoint; GraphiQL IDE on GET when GRAPHIQL=true
GET/admin/staff sessionDjango admin
